This page connects your browser to the DeepSeek Harness running on your own computer. Traffic is end-to-end encrypted: this relay forwards it without being able to read it.

On the computer running DSH, run drdsh daemon pair (or drdsh-daemon pair) and keep the command running. Codes expire after five minutes and can be used for one attempt, even if it fails.

Enter the pairing code and press Connect or Enter. Pairing saves this computer and opens Harness automatically when DSH is running.

      Setup and troubleshooting
      • On the DSH computer, check drdsh daemon status. If the service is stopped, run drdsh daemon start. Use drdsh daemon logs --follow or drdsh daemon doctor to investigate a failure.
      • Open this relay's HTTPS address on remote devices. The browser and daemon must reach the same relay; localhost HTTP is only for testing on the relay computer.
      • To pair another computer, run drdsh daemon pair there and enter its code here. Existing pairings stay in Your computers.
      • Forgetting removes saved pairings from this browser. To revoke access on the DSH computer, use drdsh daemon devices, then drdsh daemon devices --revoke <id>. Read local audit and crash reports with drdsh daemon audit and drdsh daemon crashes.
      • A room key is only for a daemon explicitly configured with that same key. drdsh daemon room-key generates a new key; it does not show the installed daemon's key. Use pairing for an existing installation.
      • On the relay server, check drdsh relay status and drdsh relay logs --follow. For Release installations, drdsh relay update updates the relay and its PWA; drdsh daemon update runs separately on the DSH computer. If nginx serves the PWA directly, its static files must also be updated.
